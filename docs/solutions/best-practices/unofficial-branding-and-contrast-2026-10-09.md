# Why the Site Does Not Copy DeepLearning.AI's Look

## Question

Should the roadmap generator adopt DeepLearning.AI's visual identity?

## What DLAI's site actually uses (checked 2026-10-09)

From deeplearning.ai's own CSS (`--color-brand-*` tokens) and screenshots:

- Near-white page background, dark ink `#13131a`, coral `#f65b66` as the brand and CTA colour (logo, "Log In", "Start Now").
- Poppins headings, Inter/Geist body, navy/purple hero art.
- Their dark-mode tokens (`#13131c` fog, coral, emerald `#2dd4a7`, indigo `#8c7fff`, a faint grid) are already close to this site's dark "neural" palette, so the two sites read as related without being copies.

## Decision: keep the site's own identity

1. **Not mistaken for an official product.** This is a community project, not a DeepLearning.AI product. Copying the coral logo colour, typography and layout would make it look like a DeepLearning.AI page, which invites confusion about endorsement. Naming the courses is fine (nominative use); dressing up as the company is not.
2. **Accessibility.** DLAI's coral CTA with white text is 3.18:1, below WCAG AA (4.5:1) for normal text. Copying it would be a regression; the current cyan-gradient CTA with dark text is 6.0-11.2:1 across the gradient.
3. **No functional gain.** Users come for the roadmap content; a re-theme touches every component for no change in what the tool does.

## What was actually wrong, and fixed

- `--text-muted` `#55556a` was 2.1-2.7:1 on our surfaces and was used for real text (course hours, footers, the tagline). Now `#8c8ca4` (4.6:1 worst case on `--elevated`). `--text-secondary` went `#8888a0` -> `#a0a0b8` (4.38 -> 5.9:1 on `--elevated`).
- The page title ("DeepLearning.AI Roadmap Generator") and the PDF footer ("Generated by DeepLearning.AI Learning Roadmap Generator | deeplearning.ai") read as official. Both now say unofficial / not affiliated, and the PDF footer is on every page in slate-600 (7.6:1) instead of slate-400 (2.6:1) on the last page only.
- The active category tab in CourseSelector used `text-[var(--bg-primary)]`, a variable that does not exist, so its label inherited near-white text on cyan. It now uses `--void`.
- Added a provenance line to the welcome and roadmap footers, PDF and README (wording corrected the same day, see below).
- The welcome footer was `absolute bottom-6` and overlapped the last feature card on mobile; it is now in normal flow.

## Guard rails

`tests/branding-a11y.spec.cjs` fails if any text token drops below 4.5:1 on any surface token, if the disclaimer disappears from the welcome or roadmap view, if the PDF claims to be generated by DeepLearning.AI, or if the welcome footer overlaps the cards on a 390px screen. When adding a new surface or text token, add it to the contrast test.

## Correction: "not affiliated" was wrong

The first version of the disclaimer said "Not affiliated with or endorsed by DeepLearning.AI". That is inaccurate. The project started in DLAI's own Community Program (the private *Testers / Project RoadMap* forum category, run by DLAI's Community-Team staff), and the public launch thread says so: https://community.deeplearning.ai/t/deeplearning-ai-course-roadmap-tool-personalized-study-plans/885591.

What is true and checkable: it started in the DLAI Community Program, it is built and hosted by a community member, and it is not an official DeepLearning.AI product. Nothing on record shows DLAI endorsing the finished tool, so the wording claims neither endorsement nor its absence. The current line is "Community project started in the DeepLearning.AI Community Program. Not an official DeepLearning.AI product." It links to the public thread, never to the private category, which returns 404 to non-members.

The program origin is a strength worth showing: it tells learners where the tool came from without overclaiming.

Material the program shared privately must stay out of this public repo and site. `courses.json` is built from public sources (the deeplearning.ai catalog payload and sitemap, plus Coursera), per the catalog-sync note.
